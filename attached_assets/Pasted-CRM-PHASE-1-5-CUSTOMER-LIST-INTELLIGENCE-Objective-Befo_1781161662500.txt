CRM PHASE 1.5 – CUSTOMER LIST INTELLIGENCE

Objective

Before expanding into Notes, Timeline, Account Health, and Customer 360 features, improve the CRM customer list so sales reps and managers can efficiently navigate, filter, segment, and work through 8,000+ customer records.

This phase focuses entirely on customer list usability, filtering, segmentation, and personalization.

DO NOT modify existing CRM metrics logic, customer profile pages, sync logic, exports, or CRM maintenance tools unless required for this phase.

---

1. CUSTOMER GROUP FILTER

---

Add a new dropdown filter above the CRM customer list:

Label:
Customer Group

Default:
All Groups

Behavior:

• Load all available customer groups from customers_mirror.customer_group_name
• Build dropdown dynamically
• Do not hardcode group names
• Selecting a group filters the customer list instantly
• Selecting "All Groups" removes the filter

Examples:

All Groups
Approved Customers
NC Active
Cloud9Only
Wholesale Customers
Cash & Carry
etc.

Filtering must work together with:
• Search
• State Filter
• Future filters

6. SAVE USER COLUMN PREFERENCES

---

Column visibility selections must persist.

When user returns:

• Previously hidden columns remain hidden
• Previously visible columns remain visible

Use existing settings architecture if available.

Preference should be stored per user.

Example:

User A:
Shows Revenue
Hides Email

User B:
Shows Email
Hides Revenue

Each user sees their own saved configuration.
