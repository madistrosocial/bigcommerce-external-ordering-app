Replit Prompt

We are pausing all work on the Native BigCommerce Store Credit feature.

Do NOT modify any POS, Store Credit, Checkout, Order Creation, Gift Certificate, Discount, or OAuth business logic.

The only objective is to determine why the BigCommerce OAuth app installation does not complete.

Objective

Perform a root-cause investigation of the OAuth installation flow only.

Do not make assumptions. Do not implement workarounds. Do not redesign the OAuth flow. First collect evidence and identify exactly where the installation process stops.

Investigation Scope

Trace the complete BigCommerce OAuth installation flow:

User clicks Install in the BigCommerce Control Panel.
BigCommerce redirects to our configured Auth Callback URL.
/api/bc/auth is invoked.
Authorization code is received.
Authorization code is exchanged for an access token.
Access token is stored.
Response is returned to BigCommerce.
Installation completes.

Determine exactly which step fails.
