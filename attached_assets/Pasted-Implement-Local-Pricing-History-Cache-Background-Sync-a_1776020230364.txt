Implement Local Pricing History Cache, Background Sync, and Search Result Improvements.

This should be an additive update. Do NOT refactor existing pricing, search, or backend logic.

---

1. LOCAL PRICING CACHE

- Create a local IndexedDB store that mirrors the existing Postgres price_history table exactly.
- Do NOT modify or reinterpret the schema.
- Prevent duplicate entries based on existing backend uniqueness logic.

---

2. SYNC BEHAVIOR

Device-specific behavior:

- Mobile:
  - Do NOT download or sync pricing history.

- Tablet:
  - On login/POS load, prompt:
    "Download pricing history for faster search?"
  - If accepted → start sync
  - If declined → do nothing

- Desktop:
  - Automatically start sync when user is idle (no typing/scanning for a short period)

---

3. SYNC LOGIC

- Sync pricing history from the app database into IndexedDB.
- Use incremental syncing (only new records after last local timestamp).
- Process in batches.
- Pause immediately if user starts interacting (typing/scanning).
- Resume when idle again.

---

4. LOCAL LOOKUP PRIORITY

Update price history lookup flow:

- First check IndexedDB
- If found → return immediately
- If not → fallback to existing backend logic

Do NOT remove backend fallback.

---

5. SYNC INDICATOR (UI)

Add a small indicator at bottom-left of POS:

- Shows only during sync
- Text:
  "Syncing pricing history..."
- Small and non-intrusive (~10px text size)
- Include subtle loading indicator (e.g., animated dots)
- Hide or fade after completion

---

6. SEARCH RESULT IMPROVEMENTS

- For mother product cards:
  - Compute and display total inventory (sum of all variants)

- Sorting:
  - Keep existing search relevance logic
  - After that, move products with zero total inventory to the bottom

- Search persistence:
  - Do NOT clear search results after:
    - adding to cart
    - selecting variant
    - closing variant popup
  - Only clear when user explicitly clicks the search clear (X)

---

7. DO NOT MODIFY

- Existing pricing logic or priority system
- Price tier logic
- Backend APIs
- Existing search matching behavior
- Cart behavior

---

OUTPUT:

- Local IndexedDB pricing cache
- Background sync (device-aware, idle-based)
- Faster price history lookup
- Small sync indicator during background download
- Improved search UX:
  - total inventory visible
  - out-of-stock products pushed last
  - persistent results
