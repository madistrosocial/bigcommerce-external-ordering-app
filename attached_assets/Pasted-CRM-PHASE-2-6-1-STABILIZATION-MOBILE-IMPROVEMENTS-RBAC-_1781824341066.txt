==================================================================
SECTION 1: COMPLETE CRM VISIBILITY RBAC
=======================================

Current Issue:

Visibility filtering works.

Admins see all customers.

Agents see assigned customers.

However visibility control is not exposed in User Management.

Administrators cannot configure which users see all customers versus assigned customers only.

==================================================================
NEW CRM PERMISSIONS
===================

Under CRM permissions add:

CRM > View All Customers

CRM > Assign Sales Rep

CRM > Export CRM Data

These must be individually configurable.

==================================================================
CRM > VIEW ALL CUSTOMERS
========================

Enabled:

User can view all CRM customers.

Disabled:

User can only view assigned customers.

This replaces any hardcoded role-based logic.

Visibility must be controlled entirely through RBAC.

Examples:

Admin

View All Customers = ON

Sales Manager

View All Customers = ON

CNC Team

View All Customers = ON

Onsite Sales Rep

View All Customers = OFF

Result:

Only assigned customers visible.

SECTION 2: FIX HEALTH CARD VISIBILITY BUG
=========================================

Current Issue:

Customer table respects visibility.

Health cards do not.

Example:

User sees:

3 customers

Health cards show:

8,302 total customers

This is incorrect.

==================================================================
REQUIRED BEHAVIOR
=================

Health cards must calculate using the same filtered dataset used by the customer table.

Cards:

Total

Healthy

Watch

At Risk

Lost

must all respect:

* Visibility scope
* Assigned rep filter
* Group filter
* State filter

Example:

Rep sees 100 assigned customers.

Healthy = 20
Watch = 10
At Risk = 15
Lost = 55

Cards should display:

Total = 100
Healthy = 20
Watch = 10
At Risk = 15
Lost = 55

Never global totals.

========================

Exports must respect visibility rules.
