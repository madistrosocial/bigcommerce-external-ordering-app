CRM Customer Master Data Enhancement (Pre-Zoho Foundation)

Objective

Enhance the CRM customer master record to support future Zoho CRM integration, RouteIQ workflows, customer segmentation, and sales team assignments.

This update should ONLY focus on:

1. Primary Rep / Secondary Rep framework
2. Customer Type
3. Address Type
4. Customer list filters
5. Customer page enhancements
6. Export enhancements

Do NOT build any Zoho CRM integration yet.

Do NOT modify existing CRM Notes, Store Credit, Customer Health, Reactivation, or RouteIQ functionality.

This is a customer master data enhancement only.

⸻

Primary Rep / Secondary Rep Framework

Database

Add the following fields to the customer master record:

primary_rep_id INTEGER NULL
secondary_rep_id INTEGER NULL

Both fields should reference existing users.

No customer assignments currently exist in production, therefore no data migration is required.

Default:

Primary Rep = NULL
Secondary Rep = NULL

⸻

Assignment UI

Replace the existing single assignment structure with:

Primary Rep
Secondary Rep

Requirements:

* Both use existing user selector components.
* Both are optional.
* Primary Rep and Secondary Rep can be different users.
* Prevent selecting the same user for both fields.
* Save immediately through existing customer update APIs.
