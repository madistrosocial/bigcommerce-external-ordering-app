# Orders Module Consolidation & ERP UI Update

Goal

This is a full implementation of the new Orders module. The goal is to replace the existing fragmented order pages with a single centralized Orders experience that follows the SalesCore Design System already established in the CRM module.

This is intended to be completed in one phase.

Use the CRM module as the visual reference for typography, spacing, filters, tables, buttons, dialogs, badges, hover states, and responsiveness.

Do not redesign independently.

----------------------------------------------------

Navigation

Replace the current structure:

Orders
- My Orders
- All Orders
- BC Orders

with

Orders
- Drafts (leave completely unchanged)
- Orders

Only Orders is being redesigned.

----------------------------------------------------

Data Source

The Orders page should load from the local database only.

Do not fetch directly from the BigCommerce API for page rendering.

BigCommerce remains the source of truth, but the UI should use the local mirrored database for speed, consistency, searching, filtering, and future reporting.
