Build MARKETING MODULE – PHASE 1 for the MidAtlantic Distribution Sales application.

IMPORTANT:
Do not redesign, refactor, rename, or break any existing working modules, APIs, routes, database tables, POS logic, Catalog, Cart, Pricing, Inventory, CRM, Orders, or authentication.

This is an ADDITIVE update.

Preserve the existing application architecture, styling system, permissions, navigation behavior, and responsive layout.

==================================================
PHASE 1 GOAL
==================================================

Build the foundation of the new Marketing module.

Phase 1 should provide:

1. Marketing Dashboard
2. Marketing Campaign Management
3. Customer Audience / Recipient Selection
4. Basic Campaign Analytics and Activity
5. Marketing navigation and permissions
6. Mobile-responsive UI

Do not build advanced automation workflows, complex customer journeys, SMS infrastructure, or advanced marketing integrations yet. Those belong to later phases.

==================================================

==================================================

Add a new main navigation item:

Marketing

IMPORTANT PLACEMENT:

Place Marketing:

Inventory
Marketing
Catalog

- Do not permanently display the submenu unless Marketing is expanded.

Mobile:
- Marketing should appear inside the existing slide-out navigation drawer.
- It must expand/collapse exactly like Inventory, Customers, Orders, etc.
- Do not create a separate mobile navigation experience.

Use a marketing/megaphone-style icon consistent with the existing icon system.

Marketing submenu:

- Marketing Dashboard
- Campaigns
- Audiences

Suggested routes:

/marketing
/marketing/campaigns
/marketing/audiences

Do not break existing routes.
