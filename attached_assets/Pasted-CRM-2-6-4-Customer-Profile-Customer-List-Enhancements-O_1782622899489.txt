CRM 2.6.4 – Customer Profile & Customer List Enhancements

Objective

Implement the remaining CRM enhancements before starting the new Campaign Orders module.

This update is strictly limited to the CRM module.

⸻

1. Fix CRM Notes Sync Bug (Highest Priority)

Current Bug

Creating CRM Notes incorrectly appends the note into the Customer Account Notes (BigCommerce customer note).

This is incorrect.

⸻

Correct Behavior

Customer Account Notes

The dedicated Customer Account Notes textarea is the only UI responsible for updating the BigCommerce customer note.

It should:

* Load from BigCommerce customer note
* Save back to BigCommerce customer note
* Respect existing RBAC permission
* Continue functioning exactly as it does now

⸻

CRM Notes

CRM Notes are completely separate.

Creating or editing any CRM Note must NEVER update the BigCommerce customer note.

The following CRM note types remain CRM-only:

* General
* Follow Up
* Sales
* Issue
* Replacement
* Credit
* Internal
* Visit
* Any future CRM note category

⸻

Order Notes

Keep current behavior if Order Notes intentionally sync elsewhere.

Do not change unless currently broken.

⸻

2. CRM Customer List

Add City Column

Add a new optional column:

City

Data source:

Customer primary address (same source currently used by CRM).

Requirements:

* Available in Show/Hide Columns
* Sortable
* Filterable
* Included in Export

⸻

Add Last Follow-Up Column

Display:

Latest CRM Note of category:

Follow Up

Display:

* Follow-up Date
* (Optional) Rep Name underneath if space allows

Requirements:

* Available in Show/Hide Columns
* Sortable
* Filterable (where practical)
* Included in Export

If no Follow Up note exists:

Display:

No Follow-Up

⸻

3. Customer Profile

Replace Shipping Address Display

Instead of displaying one fixed shipping address,

display a dropdown containing every address in the customer’s BigCommerce Address Book.

The dropdown should display each address in full.

Example:

Store Location
3417 Douglas Ave, Suite 3, Racine, WI 53402, United States

Warehouse
1200 Industrial Rd, Chicago, IL 60608, United States

Secondary Store
51 Main Street, Orlando, FL 32801, United States

If an address has no company/location name, simply display the full formatted address.

⸻

Address Dropdown Behavior

Location:

Customer card

Immediately above:

Store Type

Address Type

The selected address displays in a single line.

Changing the dropdown simply changes which address is displayed.

This is display-only.

Do NOT edit addresses.

Do NOT save selection.

No database changes.

No sync changes.

Always populate from the synced BigCommerce Address Book already stored in the app.

⸻

Address Formatting

Display as:

Address1, Address2, City, State Province ZIP, Country

Omit empty values cleanly.

No stacked lines.

Always display as one single readable line.

⸻

Database

No schema changes.

Reuse existing synced customer address data.

⸻

UI Requirements

Maintain existing CRM styling.

Dropdown width should match the customer card layout.

If only one address exists:

Still display the dropdown (for consistent UI).

⸻

Acceptance Criteria

✓ CRM Notes no longer update Customer Account Notes.

✓ Customer Account Notes remain the only editor for BigCommerce customer notes.

✓ City column added.

✓ City sortable.

✓ City filterable.

✓ City exportable.

✓ Last Follow-Up column added.

✓ Last Follow-Up sortable.

✓ Last Follow-Up filterable where applicable.

✓ Last Follow-Up exportable.
