5. LOCATION DATA COLLECTION
==================================================

Location is audit evidence, not a surveillance UI.

At Time In collect:

• timestamp
• latitude
• longitude
• accuracy
• start method
• verification result

At Time Out collect:

• timestamp
• latitude
• longitude
• accuracy
• verification result

While clocked in:

Attempt an attendance location checkpoint approximately every 1 hour.

IMPORTANT PLATFORM LIMITATION:

Normal iOS/Android browser/PWA environments cannot guarantee background geolocation while the page is backgrounded, minimized, or closed.

Therefore:

• implement hourly checkpoints as best effort
• do not claim guaranteed background tracking
• do not fabricate missing coordinates
• if a checkpoint cannot be collected, record it as missing/failed
• do not continuously collect GPS every few seconds
• do not expose hourly tracking to the employee UI

Only collect attendance-relevant location events.

==================================================

Automatic driving detection is not guaranteed in a normal browser/PWA.

Implement what the platform reliably supports.
