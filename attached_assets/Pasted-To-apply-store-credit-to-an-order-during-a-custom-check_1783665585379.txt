To apply store credit to an order during a custom checkout, you must use BigCommerce's Storefront Checkouts API. This API safely alters the checkout session on behalf of the logged-in customer.⚠️ Critical PrerequisiteThe customer must be logged into their storefront account for this endpoint to work. The Storefront API reads the customer's active web session cookie to verify identity and check their available store credit balance. It cannot be executed purely server-to-server without a customer session.The API RequestTo apply the store credit, send a POST request to the Add Checkout Store Credit endpoint.HTTP Method: POSTURL Structure: https://<your-storefront-domain>/api/storefront/checkouts/<checkoutId>/store-creditHeaders: Accept: application/jsonExample Fetch Implementation (JavaScript)javascriptconst checkoutId = "your-checkout-id-here"; // This matches your Cart ID

fetch(`/api/storefront/checkouts/${checkoutId}/store-credit`, {
    method: 'POST',
    headers: {
        'Accept': 'application/json',
        'Content-Type': 'application/json'
    }
})
.then(response => {
    if (!response.ok) {
        throw new Error('Failed to apply store credit. Ensure user is logged in.');
    }
    return response.json();
})
.then(checkoutData => {
    console.log('Store credit successfully applied!', checkoutData);
    // The returned checkout object will reflect the updated grand total
})
.catch(error => console.error('Error:', error));
Use code with caution.Alternative: Using the Checkout SDKIf you are building a custom React or Vue frontend using the BigCommerce Checkout SDK, you do not need to make manual HTTP requests. Store credit is automatically controlled when submitting the order.When you call submitOrder, explicitly pass the useStoreCredit flag in your payload:javascriptservice.submitOrder({
    useStoreCredit: true
});
Use code with caution.Common Gotchas404 / Method Not Found Error: If you receive a 404 error while calling this endpoint, it usually means the shopper is either not logged in, or they have zero store credit available in their account profile.Currency Match: BigCommerce only permits store credit usage if the checkout currency exactly matches the store's default base currency.If you would like to expand your implementation, let me know:Are you building a headless storefront or customizing a Stencil theme?Do you need assistance fetching the shopper's store credit balance before they reach the payment step?
