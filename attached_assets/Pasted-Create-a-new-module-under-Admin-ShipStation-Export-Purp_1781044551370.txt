Create a new module under:

Admin
└── ShipStation Export

Purpose:
Generate scheduled export files from ShipStation and automatically upload them to an FTP/SFTP server. This will be used to provide shipping cost information to external systems such as dropshippers and Duoplane.

Requirements:

1. ShipStation Configuration

Create a configuration card with:

- API Key
- API Secret
- Test Connection button
- Last Successful Sync timestamp
- Last Export timestamp

Store settings in the existing application settings table.

2. Export Fields Configuration

Allow admin to select which ShipStation fields should be exported.

Available fields:

- Order Number
- Tracking Number
- Shipping Cost
- Ship Date
- Carrier
- Service
- Customer Name
- Order Date
- Shipment ID

Default selected fields:

- Order Number
- Tracking Number
- Shipping Cost
- Ship Date

The export builder should dynamically generate the CSV columns based on selected fields.

3. Export Schedule

Add scheduling options:

- Manual Only
- Every Hour
- Every 2 Hours
- Every 4 Hours
- Every 6 Hours
- Daily

If Daily is selected:

- Allow selecting export time

Example:
5:00 PM
6:00 PM
7:00 PM
Custom

The export process should only include shipments that have not already been exported.

4. Export Criteria

Add options:

Shipment Status:

- Shipped Only
- Delivered Only
- All Shipments

Default:
- Shipped Only

Export Window:

- Today
- Yesterday
- Since Last Export
- Custom Range

Default:
- Since Last Export

5. FTP / SFTP Configuration

Connection Settings:

- Protocol (FTP / SFTP)
- Host Name
- Port
- Username
- Password
- Remote Folder

Add:

- Test Connection button

Display clear success and failure messages.

6. File Naming Settings

Allow admin to configure:

Base File Name

Example:

shipping_feed

Date Stamp Options:

- None
- YYYY-MM-DD
- YYYYMMDD
- YYYYMMDD_HHmm

Examples:

shipping_feed.csv
shipping_feed_2026-06-10.csv
shipping_feed_20260610.csv
shipping_feed_20260610_1800.csv

File Format:

- CSV
- TXT

Default:
- CSV

7. Export History

Create a history table showing:

- Export Date
- File Name
- Record Count
- Status
- Error Message (if failed)

Add Download button for previously generated files.

8. Database

Create tables as needed for:

shipstation_export_settings
shipstation_export_history

Store:

- configuration
- export logs
- last export timestamps

9. Export Process

Workflow:

ShipStation
↓
Retrieve shipments matching criteria
↓
Generate export file
↓
Upload to FTP/SFTP
↓
Save export history
↓
Update last successful export timestamp

10. Initial MVP

Focus on supporting the following fields first:

- Order Number
- Tracking Number
- Shipping Cost
- Ship Date

Additional fields can remain configurable but these are the primary use case.

11. UI

Follow existing Admin Settings styling.

Add menu item:

Admin
└── ShipStation Export

Use existing app patterns for:

- settings storage
- scheduled jobs
- background processing
- success/error notifications

12. Future Ready

Design the export engine so it can later support:

- multiple export profiles
- multiple FTP destinations
- vendor-specific mappings
- API exports instead of FTP
- email delivery of export files

Do not implement future features now. Only design the architecture so future expansion is easy.
