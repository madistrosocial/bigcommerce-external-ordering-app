Background

SalesCore has evolved far beyond its original purpose as a POS/CRM integration with BigCommerce.

The long-term vision is for SalesCore to become the primary ERP system for our wholesale distribution business.

The existing database and application architecture grew organically as new features were added. While the current implementation works well, it was not originally designed around a complete ERP architecture.

Before building the next generation of modules (CRM, Product 360, Inventory, Purchasing, Reporting, etc.), I want to design a cohesive long-term architecture that minimizes redundancy, reduces future rewrites, and provides a scalable foundation for the next 5–10 years.

This task is planning only.

No implementation should be performed.

Objective

Perform a complete architectural review of the current application and produce an ERP Architecture Proposal and Implementation Roadmap.

The proposal should focus on designing the best long-term ERP architecture while also providing a practical migration path from the existing system.

The current codebase should influence the migration strategy, not the target architecture.
